Embeddable Chat Widget

Add a Knowledge Expert chat widget to your website

Quick Setup

Add this single line of code to your website, just before the closing </body> tag:

<script src="/static/js/widget.js" data-api-key="YOUR_API_KEY"></script>
Log in to see your personalized embed code with your API key.
Advanced Configuration

For more control, use the JavaScript API:

<script src="/static/js/widget.js"></script>
<script>
KnowledgeExpert.init({
    apiKey: 'YOUR_API_KEY',
    apiUrl: '',

    // Appearance
    position: 'bottom-right', // or 'bottom-left'
    primaryColor: '#0d6efd',
    width: '380px',
    height: '500px',

    // Content
    title: 'Knowledge Expert',
    subtitle: 'How can we help you?',
    placeholder: 'Type your question...',
    welcomeMessage: 'Hello! How can I help you today?',
    buttonIcon: '💬'
});
</script>
JavaScript API

Control the widget programmatically:

Method Description
KnowledgeExpert.init(config) Initialize the widget with configuration options
KnowledgeExpert.open() Open the chat widget
KnowledgeExpert.close() Close the chat widget
Example: Open widget on button click
<button onclick="KnowledgeExpert.open()">
    Need help? Chat with us
</button>
